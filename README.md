# Skill-check macro (RedM)

มาโครเล่นมินิเกมวงกลม W/A/S/D อัตโนมัติ ทำงานเฉพาะตอนวงกลมขึ้นกลางจอ

## ใช้งาน
1. ดับเบิลคลิก `run_goldpan.bat` (ขอสิทธิ์ Administrator เอง ไม่มีหน้าคอนโซล)
2. เข้าเกม กด `F9` เริ่ม
3. ปิด: กด `F10` หรือดับเบิลคลิกขวาที่ HUD หรือรัน `stop_goldpan.bat`

| ปุ่ม | ทำอะไร |
|---|---|
| F9 | เริ่ม / หยุด |
| F10 | ออกโปรแกรม |
| F11 | ซ่อน / แสดง HUD |

## ไฟล์
- `goldpan_macro.py` ตัวมาโคร ค่าปรับอยู่บนสุดของไฟล์
- `run_goldpan.bat` รันแบบ HUD ไม่มีคอนโซล
- `run_goldpan_console.bat` รันแบบเห็น log (ต้อง Run as administrator เอง)
- `stop_goldpan.bat` หยุดมาโครที่ค้างอยู่
- `templates/` รูปตัวอักษร W A S D จากเกมจริง

## ฟีเจอร์
- อ่านตัวอักษรกลางวง จับเข็มกับโซน กดตอนเข็มถึงกลางโซน
- ล็อกปุ่ม W/A/S/D จากคีย์บอร์ดจริงระหว่างมินิเกม กันเผลอกด (`BLOCK_KEYS`)
- กันเปิดซ้ำ เปิดได้ทีละตัว
- เซฟภาพทุกครั้งที่กดไว้ใน `debug/` เอาไว้ไล่ปัญหา

## ข้อกำหนด
- จอ 1920x1080 เกมเป็น Borderless หรือ Windowed
- จอขนาดอื่นแก้ `CX, CY` ในไฟล์
- กดเร็วหรือช้าไป ปรับ `AIM` กับ `LEAD_SEC`
